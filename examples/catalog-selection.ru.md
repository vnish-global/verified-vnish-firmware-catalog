# Как найти маршрут прошивки VNISH для своего Antminer

Нужны два точных признака: модель Antminer и установленная контрольная плата. L9 с Amlogic и L9 с CVITEK используют разные записи. Antminer S19 и Antminer S19 (126) тоже являются разными моделями

## Перейдите к инструкции для своей конфигурации

Пример использует опубликованный снимок каталога от 24 сентября 2026 года. Текущая версия в этом снимке: 1.3.6. Notebook при каждом запуске показывает дату данных и не обращается к живому каталогу за обновлениями

Для **Antminer L9 с Amlogic** выбрана запись `l9-aml-nand-v1.3.6`

| Сайт | Точная инструкция из сохранённых метаданных |
|---|---|
| VNISH GLOBAL | [Установка на L9 Amlogic](https://vnish.global/install/l9-aml-nand/) |
| ROI ASIC | [Установка на L9 Amlogic](https://roiasic.com/install/l9-aml-nand/) |
| VNISH Ninja | [Установка на L9 Amlogic](https://vnish.ninja/install/l9-aml-nand/) |

Если установлена **CVITEK**, нужен маршрут CV: [VNISH GLOBAL](https://vnish.global/install/l9-cv-nand/), [ROI ASIC](https://roiasic.com/install/l9-cv-nand/), [VNISH Ninja](https://vnish.ninja/install/l9-cv-nand/)

Перед установкой сопоставьте маркировку устройства, плату и текущую стоковую прошивку с действующей инструкцией выбранного сайта. Поле `nand` описывает тип пакета и не означает одинаковую процедуру установки для любой стоковой прошивки

## Повторите выбор самостоятельно

Откройте [исполняемый notebook с сохранённым результатом](catalog-selection.ipynb). Готовый результат можно прочитать на GitHub без запуска кода. Для выполнения ячеек нужен Jupyter или редактор notebook с ядром Python и полная копия репозитория; рабочая папка должна быть корнем репозитория или `examples/`. Код ячеек использует стандартную библиотеку Python

В ячейке примера замените `MODEL_ID` и `BOARD_CODE`, затем выполните все ячейки. Точные идентификаторы перечислены в [catalog.json](../data/current/catalog.json). Пример:

1. Сверяет сохранённый каталог с его локальным DIGEST
2. Находит совпадение модели, платы, типа пакета и признака `is_default`
3. Сопоставляет метаданные выбранного файла в трёх сохранённых исходных каталогах
4. Показывает имя файла, опубликованный хеш, дату снимка и записанную ссылку на инструкцию каждого сайта

Код только читает локальные JSON. Он не скачивает прошивки, не открывает сетевые соединения и не управляет майнером. Хеш прошивки берётся из опубликованных метаданных; заново вычисленного хеша бинарного файла здесь нет

## Почему недостаточно названия маршрута

В [routes.csv](../data/current/routes.csv) находятся 76 текущих маршрутов снимка. В [builds.csv](../data/current/builds.csv) находятся 224 записи трёх релизов. Один `route_id`, например `l9-aml-nand`, встречается в нескольких версиях

Поэтому пример останавливается при неизвестной плате, отсутствующей комбинации, дублировании текущей сборки или расхождении источников. Похожая модель либо старая версия автоматически не подставляются. Исторические сборки сохранены в каталоге; архивную версию и её инструкцию следует выбирать отдельно
