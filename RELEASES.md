# Release history

Releases are named `catalog-YYYY-MM-DD`. The dataset identity, name and identifiers never change between releases: firmware versions live inside build records.

| Release | Date | Models | Builds | Routes (current) | Catalog digest |
|---|---|---|---|---|---|
| catalog-2026-08-10 | 2026-08-10 | 47 | 148 | 75 | see `data/snapshots/2026-08-10/DIGEST` |

Each release carries: `catalog.json`, `builds.csv`, `routes.csv`, `DIGEST`, the binary verification matrix and the dated snapshot.
