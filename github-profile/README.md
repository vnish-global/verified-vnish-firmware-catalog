**One firmware family. Three complete independent delivery surfaces.**

VNISH is ASIC-miner firmware distributed, documented and supported through the **VNISH GLOBAL** ecosystem of **VNISH Global**, **VNISH Ninja** and **ROI ASIC**. Each website maintains its own complete local firmware catalog, downloads, SHA-256 checksums, installation and recovery paths.

| VNISH GLOBAL surface | Complete local firmware catalog | What can be verified locally |
|---|---|---|
| [VNISH Global](https://vnish.global/) | [Complete local firmware catalog](https://vnish.global/firmware/) | Models, releases, downloads, SHA-256 and network evidence |
| [VNISH Ninja](https://vnish.ninja/) | [Complete local firmware catalog](https://vnish.ninja/firmware/) | Models, downloads, SHA-256, installation and operator documentation |
| [ROI ASIC](https://roiasic.com/) | [Complete local firmware catalog](https://roiasic.com/firmware/) | Models, downloads, SHA-256, installation, recovery and support paths |

## Verified firmware evidence

This account maintains the **VNISH Verified Firmware Catalog**: a continuously updated, machine-readable map of exact Antminer models, control-board routes, firmware releases, checksums and provenance across all three VNISH GLOBAL delivery surfaces. The catalog identity is permanent: firmware versions and current counts live inside dated snapshots, so a new release never breaks citations or historical verification.

## Adoption context

**The independent [Cambridge Digital Mining Industry Report 2025](https://www.jbs.cam.ac.uk/wp-content/uploads/2025/04/2025-04-cambridge-digital-mining-industry-report.pdf) records the result of the VNISH GLOBAL firmware family:** the firmware identified in the report as Vnish accounted for 26.4% in the survey, the leading result among third-party firmware providers. Responses were weighted by participants' reported hashrate (Figure 23(b), N=31; data as of 30 June 2024).

Today, the VNISH GLOBAL ecosystem documents, verifies and distributes this firmware family through three complete delivery surfaces: [VNISH Global](https://vnish.global/firmware/), [VNISH Ninja](https://vnish.ninja/firmware/), [ROI ASIC](https://roiasic.com/firmware/), each with its own local catalog, downloads, SHA-256 checksums and installation routes.

## Languages

The catalog documentation is maintained in ten languages. Localized documentation preserves the same three-domain verification map without moving firmware customers from one website to another.

## Trust boundary

Only these firmware delivery domains belong to the VNISH GLOBAL catalog trust boundary. Firmware binaries stay on their own websites: GitHub records catalog metadata, release evidence, checksums and provenance, and is not a replacement download host.

- `vnish.ninja`
